이 앱은 유튜브 데이터를 가져오려면 본인 소유의 Google API 키가 하나 필요해요. 아래 순서대로 따라 하면 돼요. 키는 완전 무료이고, 이 브라우저에만 저장되니 안심하세요.
✓ 요금 없음 · 하루 무료 할당량 안에서 사용
1

Google Cloud Console 접속 & 로그인

아래 링크를 열고 본인 Google(Gmail) 계정으로 로그인하세요. 처음이면 이용약관 동의 화면이 나올 수 있는데 체크하고 넘어가면 돼요.

→ console.cloud.google.com 열기
2

프로젝트 선택 (또는 새로 만들기)

상단 왼쪽의 프로젝트 선택 부분을 누르세요. 기존 프로젝트(예: My First Project)가 있으면 그걸 골라도 되고, 없으면 새 프로젝트를 만드세요.

3

YouTube Data API v3 사용 설정

상단 검색창에 YouTube Data API v3 를 입력해 찾은 뒤, 파란 사용 설정(Enable) 버튼을 누르세요.

→ 바로 이 API 페이지 열기
4

API 키 만들기

왼쪽 메뉴에서 API 및 서비스 → 사용자 인증 정보 로 간 뒤, 위쪽 ＋ 사용자 인증 정보 만들기 를 누르고 API 키 를 선택하세요.

5

보안을 위해 YouTube 전용으로 제한

키 만들기 화면에서 API 제한사항 → 키 제한 을 선택하고 목록에서 YouTube Data API v3 하나만 체크하세요. 이러면 키가 새어나가도 다른 곳엔 못 써서 안전해요.

⚠️ "서비스 계정을 통해 API 호출 인증" 체크박스는 비워두세요. "애플리케이션 제한사항"은 없음 그대로 두면 됩니다.

6

키 복사 → 이 앱 설정에 붙여넣기

만들기 를 누르면 AIza… 로 시작하는 키가 팝업으로 떠요. 복사 아이콘을 눌러 복사한 뒤, 이 앱의 ⚙ 설정·주제 → API 키 칸에 붙여넣으면 끝이에요!
